# Protocolos David
Un protocolo nace a la 2ª repetición de un trabajo (art. 14). Carpeta `protocolos/`. Hoy: ninguno propio.
Pasos base de sesión:
1. Abrir: constitución + libreta + tablero.
2. Trabajar un módulo, en `trabajo`.
3. Gate (tests, tipos, build) y un commit.
4. Cerrar: tablero e incidencias al día; reporte «Hecho · Pendiente tuyo».
